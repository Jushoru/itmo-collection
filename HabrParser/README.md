# Habr Article Parser
Небольшой `Python`-парсер для автоматического сбора данных статей с `Habr` по выбранному поисковому запросу.

## Особенности:

1. Запуск в `Google Colab`.
2. Использует библиотеки:
    - `requests`
    - `beautifulsoup4`
    - `pandas`
    - `time`
    - `quote_plus` из `urllib.parse`.
3. Ввод поискового запроса осуществляется в коде.
4. На выходе получается CSV-файл `habr_articles.csv`, который содержит следующие данные:
    - Заголовок
    - Сылку
    - Месяц
    - Год
    - Количество просмотров
    - Текстовое описание без картинок
