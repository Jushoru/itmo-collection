# Детекция дефектов мембран асептических упаковок при помощи модели обнаружения объектов YOLOv8
Данная директория содержит датасет и код проекта, который решает задачу автоматического контроля качества мембран асептических упаковок (например, для соков или молочных продуктов) с использованием модели **YOLOv8**. Система обнаруживает 6 типов дефектов:
- Отсутствие дефектов
- Морщины
- Оттиск на канальцах
- Смещение канальцев
- Морщины между канальцами
- Замятие мембраны

## 🛠 Технологии
- **YOLOv8s** (оптимальный баланс скорости/точности)
- **Roboflow** (разметка и аугментация данных)
- **Google Colab** (обучение на GPU Tesla T4)

## 📊 Результаты
Модель достигла **100% точности** на тестовой выборке (25 изображений):
- **Precision**: 0.995
- **Recall**: 0.968
- **mAP50**: 0.995
